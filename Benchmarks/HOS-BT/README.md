# HOS-BT Benchmark

HOS-BT is the Prolabs Robotics benchmark for comparing HOS models with each other.

Released: 24 November 2026.

## Why HOS-BT

Every HOS release is run on the same tasks with the same scoring. This shows clearly how each new model improves on the last one.
