# Introduction

Humanoid Operating System (HOS) is an AI-powered robotics planning platform that enables users to understand a physical workspace from a single image, generate intelligent robotic action plans, and simulate task execution using natural language.

Instead of manually programming every robot movement, users simply describe the desired task in plain English.

HOS combines:

- Computer Vision
- Artificial Intelligence
- Natural Language Understanding
- Motion Planning
- Robot Simulation

into one integrated platform.

# Installation

1. Install Python 3.13 or newer.
2. Install all required Python packages.

```bash
pip install -r requirements.txt
```

3. Open the source code.

4. Replace the placeholder API key:

```python
OPENAI_API_KEY = "YOUR_OPENAI_API_KEY"
```

5. Run the application.

```bash
python main.py
```

# Launching HOS

After starting the application, the main interface appears.

The interface consists of:

- Workspace Viewer
- Object List
- AI Chat

---

# User Interface Overview

## Workspace Viewer

Displays the imported image.

Detected objects are automatically highlighted and mapped onto the workspace.

---

## Object List

Every detected object includes:

- Name
- Position
- Size
- Colour
- Description
- Alternative names

Unknown objects are also displayed.

---

## AI Chat

Type natural language instructions.

Example:

```
Move the bottle beside the mug.
```

or

```
Wash every dirty plate.
```

No programming knowledge is required.

---

## Simulation Panel

Before executing a task, HOS simulates the complete robot operation.

Simulation allows you to:

- Review every robot action
- Verify task correctness
- Detect planning mistakes
- Understand robot reasoning

---

# Importing an Image

Click **Import Image**.

Supported formats include:

- PNG
- JPG
- JPEG
- TIFF

Once imported, HOS automatically:

1. Detects objects
2. Measures positions
3. Generates polygons
4. Maps objects onto the workspace grid
5. Creates the robot world model

---

# Object Detection

Every detected object contains:

- Center position
- Occupied grid cells
- Size
- Colour
- Description

Objects that cannot be identified are listed as **Unknown Objects**.

```

```

```

```


HOS automatically:

# Running the Simulation

Once planning is complete:

1. Review the generated plan.
2. Observe every movement.
3. Verify interactions.
4. Confirm completion.

The simulation represents how the robot would perform the task before execution on real hardware.

# Understanding the Workspace Grid

The workspace consists of:

- 20 columns (A to T)
- 11 rows (1 to 11)

Example coordinates:

```
A1
C5
H7
T11
```

Every object occupies one or more grid cells.

This allows accurate robot localisation.

# Best Practices

For the highest accuracy:

- Use high-resolution images.
- Ensure good lighting.
- Avoid heavy shadows.
- Minimise object overlap.
- Capture the workspace from directly above whenever possible.

# Troubleshooting

## No Objects Detected

Possible causes:

- Poor lighting
- Blurry image
- Unsupported image format

**Solution**

Import a clearer image.

---

## Incorrect Object Locations

Possible causes:

- Heavy shadows
- Reflective surfaces
- Significant object overlap

**Solution**

Retake the image with improved lighting and a top-down camera angle.

---

## AI Cannot Complete the Task

Possible causes:

- Ambiguous instruction
- Missing object
- Impossible action

Instead of:

```
Move it there.
```

Use:

```
Move the blue mug beside the kettle.
```

# Frequently Asked Questions

## Can I use any image?

Yes. Standard image formats such as PNG, JPG, JPEG, and TIFF are supported.

---

## Does the robot execute the task automatically?

No.

HOS first performs a simulation so the user can verify the generated plan.

---

## Can I customise robot behaviour?

Yes.

Use the **AI Instructions** section to define permanent planning rules.

---

## Does HOS require programming knowledge?

No.

Tasks are described using natural language.

---

## Can multiple tasks be executed?

Yes.

Simply submit another instruction after the previous task has completed.
